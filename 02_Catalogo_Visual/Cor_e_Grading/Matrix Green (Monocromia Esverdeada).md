# Matrix Green (Monocromia Esverdeada)
## Conceito Técnico
Grading que empurra toda a imagem para um matiz verde dominante, associado à estética "mundo digital/simulado" popularizada por Matrix (1999) — usado como código visual para diferenciar realidades (simulação vs. mundo real) ou para evocar corrupção tecnológica/vigilância.
---
## Efeito Psicológico e Narrativo
* **Artificialidade Sinalizada:** Avisa ao espectador que isto não é a realidade base.
* **Frieza Tecnológica:** O verde substitui a neutralidade por uma tonalidade "codificada".
* **Vigilância Digital:** Sugere monitoramento ou sistema computacional observando a cena.
---
## Aplicações Práticas
* **Cenas Dentro de Simulações/Realidade Virtual:** Camada visual de "outro mundo".
* **Ambientes de Vigilância/Hacking:** Frieza tecnológica codificada.
---
## Módulos para Engenharia de Prompt
| Parâmetro | Configuração Recomendada | Efeito no Gerador de IA |
| :--- | :--- | :--- |
| **Matiz** | `dominant green color cast, monochromatic green grade` | Ancora a assinatura cromática do gênero |
