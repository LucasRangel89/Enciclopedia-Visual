# Wes Anderson
## Conceito Técnico
Diretor conhecido por simetria rigorosa, paletas pastel específicas (mostarda, rosa, turquesa), enquadramentos frontais centralizados, movimentos de câmera planares (pan/tilt em ângulos retos), e composições que tratam o quadro como uma vitrine de diorama meticulosamente arrumada.
---
## Efeito Psicológico e Narrativo
* **Controle Absoluto:** Cada elemento parece calculado e no lugar certo.
* **Nostalgia Melancólica-Cômica:** Humor seco convivendo com tristeza contida.
* **Mundo Artificial, Emoção Sincera:** O artifício visual não anula o peso emocional real.
---
## Aplicações Práticas
* **Cenas Familiares Excêntricas:** Grupos posados com formalidade teatral.
* **Interiores Decorados como Cenário:** Ambientes tratados como vitrine.
---
## Módulos para Engenharia de Prompt
| Parâmetro | Configuração Recomendada | Efeito no Gerador de IA |
| :--- | :--- | :--- |
| **Simetria** | `perfectly centered symmetrical composition, flat frontal framing` | Força a assinatura compositiva |
| **Paleta** | `pastel color palette, mustard yellow and dusty pink tones` | Ancora a cor característica |
### 🗣️ Vocabulário para Prompt (descritivo, sem depender do nome)
* `symmetrical centered composition`
* `pastel color palette (mustard, dusty pink, teal)`
* `flat frontal framing`
* `diorama-like meticulous set design`
* `deadpan character staging`
* `vintage typewriter font signage`
* `vintage travel poster color grading`
