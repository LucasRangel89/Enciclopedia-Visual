# ⚙️ MOC — Engenharia e Receitas

Onde o conhecimento do cofre é composto em **prompts completos e reproduzíveis**. Uma receita não é uma lista de adjetivos: é uma arquitetura — sujeito, ação, meio, luz, câmera, cor, textura, atmosfera, proporção.

## Anatomia de um prompt

```
[SUJEITO] + [AÇÃO/ESTADO] + [MEIO/MÍDIA] + [LUZ] + [CÂMERA/LENTE]
+ [COR/PALETA] + [TEXTURA] + [COMPOSIÇÃO] + [ATMOSFERA] + [PROPORÇÃO]
```

Ordem importa: o que vem primeiro tem mais peso. Comece pelo que é **irreduzível** na imagem e termine pelo que é acabamento.

## Receitas canônicas

| Receita | Combina | Uso |
| :--- | :--- | :--- |
| Retrato cinematográfico | Luz Rembrandt + 85mm + f/1.8 + teal & orange | Retrato com ar de filme |
| Paisagem de fantasia épica | Luz dourada + grande-angular + paleta análoga quente | Concept art de mundo |
| Natureza-morta barroca | Chiaroscuro + textura de óleo + fundo escuro | Still-life clássico |
| Terror atmosférico | Low-key + névoa volumétrica + paleta dessaturada fria | Horror psicológico |
| Pôr de sol publicitário | High-key + simetria + saturação controlada | Imagem de produto |

## Anti-receitas (o que não fazer)

- **Empilhar adjetivos supérfluos.** "bonito, fascinante, espetacular" não muda nada para o modelo.
- **Prompt longo demais.** Além de um limite, o começo da frase é esquecido.
- **Conflito de estilos sem mediação.** "anime + renascimento" sem ponte vira híbrido desordenado.
- **Depender de nome de artista.** Muitos geradores bloqueiam; a descrição técnica é mais robusta e mais honesta.
