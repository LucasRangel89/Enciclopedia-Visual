# Enciclopédia Visual

**Um atlas interativo de linguagem visual — para direção de arte, fotografia, ilustração e engenharia de prompts de imagem.**

Cada nota deste cofre é um **átomo de conhecimento**: um conceito visual isolado, com sua definição técnica, seu efeito psicológico e narrativo, suas aplicações práticas e — sobretudo — o **vocabulário de prompt** que o reproduz num gerador de imagens.

---

## Como usar

1. **Comece pelos fundamentos.** São as nove variáveis que governam qualquer imagem: composição, cor, luz, óptica, textura, ritmo, densidade, tipografia e corpo.
2. **Navegue pelas setas laterais.** O explorador (esquerda) organiza por área; o grafo (direita) mostra como os conceitos se conectam.
3. **Use a busca.** A busca full-text indexa todo o conteúdo, inclusive as tabelas de vocabulário de prompt.
4. **Passe o mouse num link interno** para ver uma prévia sem sair da página.

> [!tip] O que procurar em cada nota
> Toda nota segue o mesmo esqueleto: **Conceito Técnico → Efeito Psicológico e Narrativo → Aplicações Práticas → Módulos para Engenharia de Prompt → Galeria multi-gerador → Prompt de referência testado.**
> Se você só quer o prompt, vá direto à última seção.
